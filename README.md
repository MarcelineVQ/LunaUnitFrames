# LunaUnitFrames
Unit Frames for Turtle WoW
---
SuperWoW/UnitXP enabled
---
Includes:
* Accurate mob cast times
* Accurate totem timers
* Perfect range checking
* Threat display for mobs via the `[threat]`, `[perthreat]`, and `[pullthreat]` tags
* * Works the same as TWThreat, in that you must be in a party and fighting an elite.
* Focus frame (SuperWoW only) — a configurable unit frame that tracks any unit by GUID
* * `/focus` — focus your current target
* * `/focus <name>` — focus a player by name (looked up via roster)
* * `/focus <unit>` — focus a unit ID (e.g. party1, raid5)
* * `/focus clear` — clear the focus frame

* Originally sourced from https://github.com/gnwl/LunaUnitFrames and https://github.com/Aviana/LunaUnitFrames
